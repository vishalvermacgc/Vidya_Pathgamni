# 🎓 Vidya Pathgamni

### Unlock Your Potential. Learn from the Best or Teach the Rest.

Vidya Pathgamni is a modern **online learning platform** designed to bring students and teachers together in a single digital learning ecosystem.

The platform provides students with an organized environment to discover courses, access video-based learning content, and track their learning progress. At the same time, teachers can create and manage educational content and share their knowledge with learners.

---

## 🌟 Overview

Traditional learning systems can often make it difficult for students to access organized educational content and for teachers to effectively distribute their knowledge.

**Vidya Pathgamni** aims to simplify this experience by providing a centralized platform where:

- Students can discover and learn from courses
- Teachers can create and manage educational content
- Learners can track their course progress
- Educational videos can be accessed through a dedicated player
- Different user roles can have dedicated dashboards

The goal is to make online education **simple, accessible, structured, and engaging**.

---

## 🚀 Features

### 📚 Course Learning

Students can explore available learning content and access courses through a dedicated learning interface.

### 🎥 Video-Based Learning

Courses can contain video lectures that students can watch through the integrated student video player.

### 📊 Student Dashboard

The student dashboard provides a centralized place to manage the learning experience, including course access and progress.

### 👨‍🏫 Teacher Dashboard

Teachers get a dedicated dashboard to manage and deliver educational content to students.

### 📈 Learning Progress

Students can keep track of their learning journey and monitor course completion.

### 🔐 Authentication

The platform includes a dedicated sign-in interface for user access and authentication.

### 🎯 Role-Based Experience

Vidya Pathgamni provides separate experiences for students and teachers, allowing each user type to interact with features relevant to them.

### 🎨 Modern User Interface

The platform uses a clean, modern educational design focused on readability, accessibility, and ease of navigation.

### 📱 Responsive Design

The interface is designed to provide a smooth experience across different screen sizes and devices.
